# Contributing

Status: stub. The full contribution interface will be authored in Phase 5 of the project (see `PROJECT_BRIEF.md`).

## What this project is

The EU AI Security Mapping is a vendor-neutral practitioner framework. Its core deliverables (threat model, controls library, regulatory crosswalk, practitioner guide) are independent practitioner work and do not contain vendor names or branding.

Vendor-specific content lives in a separated mapping layer. Vendors and community contributors will be able to submit mappings of specific products to the framework's control library through a documented contribution interface.

## What is accepted today

| Contribution type | Status |
|---|---|
| Issues raising errors, ambiguities, or missing citations in the framework | Welcome |
| Pull requests fixing typos, broken links, or citation errors | Welcome |
| Substantive content contributions to the practitioner guide | Not accepted yet; the document is being authored by the maintainer |
| Vendor mappings | Not accepted yet; contribution interface opens in Phase 5 |
| Community mappings | Not accepted yet; contribution interface opens in Phase 5 |

## When the vendor mapping interface opens

The contribution interface will be activated after the threat model and controls library are mature enough for stable mapping. At that point this document will be replaced with full contributor guidance covering:

- Eligibility (vendor-submitted preferred; community-submitted accepted with disclosure)
- The mapping JSON schema and validation process
- Quality criteria (control IDs, vendor documentation citations, scope, last-reviewed date)
- Review process and timelines
- Recusal policy for ServiceNow-submitted mappings
- Currency and archival rules

## Code of conduct

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Maintainer affiliation disclosure

The maintainer works at ServiceNow. The framework is independent practitioner work and does not represent ServiceNow positions. The maintainer will recuse from reviewing any ServiceNow-submitted mapping; an independent reviewer will be arranged for those submissions.
