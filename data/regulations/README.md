# Source Regulation Texts

This folder will hold the primary source texts of the regulations covered by the project. Texts are stored verbatim (with citations to the official EUR-Lex / OJ publication) so claims in the main document can be traced back to authoritative sources.

## Expected files (Phase 2)

| File | Source | Notes |
|---|---|---|
| `eu-ai-act.md` | Regulation (EU) 2024/1689 | Full text, with focus on Articles 9, 10, 14, 15. Annexes included as needed. |
| `nis2.md` | Directive (EU) 2022/2555 | Articles relevant to technical security obligations. |
| `dora.md` | Regulation (EU) 2022/2554 | ICT risk management and third-party risk articles. |
| `gdpr-art-22.md` | Regulation (EU) 2016/679, Article 22 | Excerpt only; relevant to AI agent autonomy and automated decision-making. |

## Conventions

- Each file includes a header with: official title, CELEX number, OJ reference, date of publication, date of entry into force, last verified date.
- Source URL must point to EUR-Lex (consolidated version where available).
- No editorial commentary in these files; commentary belongs in `docs/sections/`.
- Updates from Official Journal corrigenda must be tracked in `CHANGELOG.md`.
