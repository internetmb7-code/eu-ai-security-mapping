# AGT-004: Data Exfiltration via Legitimate Channels

**Status**: Compressed draft. Schema-faithful but lighter detail than AGT-001 and AGT-002. Realistic example to be populated.

**Primary surface**: Output
**Secondary surfaces**: Tool-use, Memory and persistence

## Description

An AI agent transfers sensitive data outside its intended boundary using channels that are legitimate by design. Traditional data-loss-prevention assumes anomalous channels (unusual destinations, unauthorized protocols, suspicious file transfers); agents use ordinary channels in ordinary ways, but with sensitive content they were not intended to expose. The threat surfaces in agent outputs to users, tool calls to external services, and persistence to memory or vector stores, each of which is a legitimate operation when considered in isolation.

Sub-patterns include inclusion of sensitive data in user-facing responses (the agent retrieves more than required and exposes it in summary), exfiltration via tool parameters (sensitive content embedded in calls to logging, monitoring, or third-party services), and persistence into long-term memory or vector stores that are subsequently accessible across users.

## Attack scenario

A customer service agent in a regulated DACH financial services enterprise is asked to summarize a customer's recent interactions. The agent retrieves a broader interaction history than required (including conversations with other support staff that contained personal data of third parties referenced in the case), composes a summary, and includes context that the user requesting the summary is not authorized to see. No tool was misused, no authorization was exceeded at the data-retrieval layer, and the agent's intent is benign. The harm is in the output composition: legitimate retrieval, legitimate summarization, illegitimate disclosure.

## Affected components

- Agent output channels
- Tool-call parameter construction
- Memory and vector-store writes
- Downstream observability systems that ingest agent outputs
- Conversation logs

## Traditional controls and why insufficient

| Traditional control | Why insufficient |
|---|---|
| Network DLP | Tuned for unusual destinations or large transfers; agent outputs to legitimate channels evade it |
| Content classification on outbound traffic | Agents construct novel composites at the output stage that classifiers were not trained on |
| Channel-based controls | All channels used by the agent are legitimate by design |
| Output content filtering | Possible but typically tuned for known sensitive patterns (PII, credit cards); composed sensitive content evades it |

## Recommended controls

| Control | Role |
|---|---|
| CTL-004 (Authorization-aware output filtering) | Primary: filters outputs to what the requesting user is authorized to see |
| CTL-001 (Identity and authorization context propagation) | Primary: ensures the agent retrieves with appropriately scoped authorization, reducing the data available to leak |
| CTL-005 (End-to-end audit and accountability) | Detective: enables review of what the agent disclosed |

## Control gap flag

CTL-004 addresses output filtering against retrieved data. It is less direct against tool-call parameters that exfiltrate to third-party services, and against persistence into vector stores accessible across users. A v2 refinement might split output controls into user-facing and machine-facing variants.

## ATLAS mapping

AML.T0024 (Exfiltration via Cyber Means), AML.T0057 (LLM Data Leakage). Direct fit for agent context.

## Residual risk

Output filtering reduces but does not eliminate the threat. Inferential disclosure (agent summaries that reveal protected information through inference rather than direct quotation) is particularly hard to filter. Vector-store persistence creates long-lived exposure that is hard to retract once written.

## Detection and mitigation maturity

Detection: emerging. Mitigation: emerging.

Illustrates the output attack surface, specifically the pattern of sensitive data crossing trust boundaries through legitimate channels. Exemplifies how channels that are legitimate by design can carry sensitive content the agent was not intended to expose.
